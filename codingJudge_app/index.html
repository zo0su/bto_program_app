BGS 코딩 테스트 플랫폼

수업 진도에 맞춘 파이썬 실습 문제를 배포하고, 학생들의 작성 과정과 제출 상태를 한눈에 확인하는 올인원 웹 서비스입니다.

HTML + CSS + Vanilla JS BGS Coding Test

교사용 핵심 기능

  • 회원가입 승인 후 학급별 학생 일괄 등록
  • 문제 생성 · 수정 · 삭제 및 학급 배포
  • 대시보드에서 제출 여부, 정답 판별, 작성 시간 추적
  • 코드 완성도 그래프로 Ctrl+C / Ctrl+V 사용 여부 추정

학생용 핵심 기능

  • 배포된 문제 확인 및 즉시 풀이
  • 실행 결과 stdout / stderr 영역으로 즉시 피드백
  • 제출 이후에도 다시 풀기 가능
  • 제출 기록은 실시간으로 교사에게 공유

운영 플로우

1. 교사 회원가입

학교 정보를 포함한 가입 신청 → 관리자 승인 후 서비스 사용.

2. 학생 일괄 등록

제공된 XLSX 템플릿으로 최대 2,000명까지 한 번에 업로드.

3. 문제 생성 & 배포

문제 설명, 입출력, 예시 코드, 참고 이미지를 입력하고 학급 선택 후 배포.

4. 모니터링

대시보드에서 제출 상태, 정답 여부, 코드 길이 변화, 제출 시간을 즉시 확인.
